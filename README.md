## Our Projects

### RWR Package Intelligence

**Know what is changing. Update Arch Linux with confidence.**

A Rust and GTK4 graphical update manager for Arch Linux, with package intelligence, change information, and an authorized system-update workflow.

- Inspect available updates and package version changes.
- Review package information and important system updates.
- Perform authorized full-system updates through the installed backend.
- Polish and English interface with the RWR X-FILES visual identity.

**Current beta:** `v0.1.0-17-beta` — Arch Linux x86_64.

[Source code](https://github.com/runningwithrottweilers/rwr-package-intelligence) · [Download AppImage](https://github.com/runningwithrottweilers/rwr-package-intelligence/releases/download/v0.1.0-17-beta/RWR-Package-Intelligence-0.1.0-17-x86_64.AppImage) · [Download backend](https://github.com/runningwithrottweilers/rwr-package-intelligence/releases/download/v0.1.0-17-beta/rwr-package-intelligence-backend-0.1.0-17-x86_64.pkg.tar.zst) · [Release and installation](https://github.com/runningwithrottweilers/rwr-package-intelligence/releases/tag/v0.1.0-17-beta)

*The AppImage contains the graphical interface. The backend requires separate installation and administrator configuration. A real system update was performed with the earlier version 0.1.0-15; real updating with 0.1.0-17 has not yet been verified.*

### X-ARCH Theme Studio

A Linux icon theme manager built with Python, GTK4, and Rust.

- Preview and manage icon themes.
- Customize individual folder icons.
- Explore the X-ARCH Alien Themes collection.
- Current v0.5.0-beta release available for Linux x86_64:
  - [AppImage](https://github.com/runningwithrottweilers/xarch-theme-studio/releases/download/v0.5.0-beta/X-ARCH_Theme_Studio-v0.5.0-beta-x86_64.AppImage)
  - [Flatpak](https://github.com/runningwithrottweilers/xarch-theme-studio/releases/download/v0.5.0-beta/X-ARCH-Theme-Studio-v0.5.0-beta-x86_64.flatpak)

**Current release:** `v0.5.0-beta`

[Source code](https://github.com/runningwithrottweilers/xarch-theme-studio) · [Download release](https://github.com/runningwithrottweilers/xarch-theme-studio/releases/tag/v0.5.0-beta) · [Alien Themes](https://github.com/runningwithrottweilers/xarch-alien-themes)

*Note: The project is in beta. Individual folder icon customization works; full system-wide theme integration is still being refined. Compatibility has not been verified across every Linux distribution.*
